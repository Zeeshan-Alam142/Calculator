# 🧮 Simple Calculator

A responsive and user-friendly calculator built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations with a clean and modern interface.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear display
- 🖥️ Responsive design
- ⚡ Instant calculation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
